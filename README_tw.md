# Vid Auto Prompt v2.0.0

[English](README.md)

Vid Auto Prompt 是在 Windows 本機執行的網頁應用程式，可將短篇故事整理成可編輯的分鏡與 MiniMax H3 提示詞，再交由 ComfyUI 生成影片片段。你可以逐段審閱、綁定參考圖片、音訊或影片、比較多次生成結果，最後把選定的片段合併成完整影片。

## 安裝與啟動

1. 在 Windows 11 安裝 Python 3.11–3.14，並保留 `py` 啟動器。請安裝提供 `nvidia-smi` 的 NVIDIA 驅動程式，安裝腳本會檢查 NVIDIA GPU。
2. 複製倉庫後，在專案根目錄執行安裝及啟動腳本。

   ```powershell
   git clone https://github.com/LBK888/story_prompt_maker.git
   cd story_prompt_maker
   .\install.bat
   .\start.bat
   ```

3. 開啟[本機網頁介面](http://127.0.0.1:7865)。應用程式預設只接受來自本機的連線。安裝程式會建立 `.venv/`，並將通過 SHA-256 驗證的 Windows 版 llama.cpp 與 FFmpeg 下載到 `runtime/`。
4. 如需 AI 輔助撰寫，請先選擇 LLM。生成影音前請啟動並設定 ComfyUI。兩項服務都還沒設定好時，仍可建立空白分鏡、手動填寫提示詞及編輯專案。

本機推論需要自行準備 GGUF 權重。倉庫包含 121 位內建男性角色及其素材，合計約 1.58 GiB。

## 設定撰寫用的 LLM

在首頁右上角按 **模型設定**，從 **連線方式** 選擇要使用的服務。

| 連線方式 | 設定步驟 |
| --- | --- |
| 本機 llama.cpp | 把 GGUF 放在專案根目錄或 `models/`。按 **重新掃描** 後選擇模型。若要使用相容的視覺模型分析圖片，再選擇搭配的 **視覺投影模型**（mmproj）。 |
| Ollama | 啟動 Ollama 並下載模型。本機服務可填 `http://127.0.0.1:11434`，再從 API 清單選擇模型。 |
| OpenAI 或 OpenRouter | 使用預填的 API URL，輸入 API Key，按 **載入 API 模型清單** 後選擇模型。 |
| 自訂 OpenAI 相容 API | 輸入服務的 API 基底網址（通常以 `/v1` 結尾），有驗證需求時填入 API Key。載入清單或直接輸入完整模型 ID。 |

使用 API 時，也可以在 **搜尋或輸入模型 ID** 輸入完整 ID，再按 Enter 選定。使用本機 llama.cpp 時可視需求調整 **Context size**，最後按 **儲存模型設定**。API Key 留白會沿用已儲存的金鑰，金鑰會存在本機的 `.env`。

## 連接 ComfyUI

1. 另外安裝並啟動自行架設的 ComfyUI，並裝好工作流程需要的自訂節點及模型檔。自訂工作流程可先在 ComfyUI 裡用實際素材測跑一次，確認輸出節點能存檔。
2. 建立或開啟專案，按 **連線設定**。在 **ComfyUI URL** 填入服務的基底網址。本機可填 `http://127.0.0.1:8188`，區網伺服器可填 `http://192.168.1.50:8188` 這類地址。此應用程式透過 HTTP API 連線，該 API 必須可免驗證存取。[ComfyUI 伺服器 API 說明](https://docs.comfy.org/development/comfyui-server/comms_routes)
3. 本機 llama.cpp 與 ComfyUI 使用同一張顯示卡時，勾選 **與 ComfyUI 共用 GPU**。送出影片工作前，程式可先關閉自己啟動的 llama.cpp 以釋放 VRAM。若使用不同顯示卡或不同電腦，取消勾選。**中斷LLM釋放vram** 可手動關閉本機 llama.cpp，也會中斷當下的模型工作。
4. 先按 **儲存**，再按 **測試連線**。看到 **ComfyUI 已連線** 即可確認伺服器能連通。實際生成還需要工作流程所用的節點、模型、輸入素材及正確的輸出設定。

### 用關鍵字編輯器製作工作流程範本

可先試用 `t2va_template.json` 等隨附範本，並在 ComfyUI 裝好對應的依賴。也可以用編輯器製作自己的範本。

1. 在 ComfyUI 開啟測試過的工作流程，選 **File → Export (API)**。API 格式的 JSON 以節點 ID 為鍵，每個節點包含 `class_type` 和 `inputs`。[ComfyUI API 匯出範例](https://github.com/Comfy-Org/ComfyUI/blob/master/script_examples/basic_api_example.py)
2. 從本機專案資料夾用瀏覽器開啟 [ComfyUI Workflow 關鍵字編輯器](ComfyUI%20Workflow%20關鍵字編輯器.html)。按 **開啟 JSON** 選擇剛匯出的檔案，可切換 **程式碼** 與 **樹狀** 檢視。工具列也提供 JSON 格式化、復原、重做、搜尋與取代。
3. 從 **可替代欄位** 選擇要設定的輸入欄位，在 **替換為主程式 TOKEN** 選擇對應的關鍵字，再按 **套用**。找不到欄位時，可切到 **全部** 或 **未知對應**。
4. 提示詞欄位可填 `[[PROMPT]]`，存檔節點的檔名前綴必須使用 `[[OUTPUT_PREFIX]]`。依工作流程加入 `[[SEED]]`、`[[DURATION]]`、`[[WIDTH]]`、`[[HEIGHT]]` 等值。素材可用 `[[FIRST_FRAME]]`、`[[LAST_FRAME]]`、`[[REF_IMG0]]`、`[[REF_AUD0]]`、`[[REF_VID0]]`、`[[Drive_AUD]]` 等。每個關鍵字都必須占完整的 JSON 值，重複使用時會套用相同的值。[完整關鍵字清單](workflow_templates/README.md)
5. 按 **下載**，將 JSON 放入 `workflow_templates/`。若要在範本旁顯示使用說明，可填 **Template note**，再按 **下載 note**。將 `*.note.txt` 與 JSON 放在同一資料夾，兩者使用相同主檔名。備註會隨範本快照存入專案。
6. 重新整理專案頁面並在片段上套用範本。修改範本檔後，請重新套用以更新專案內的快照。

## 建立分鏡與生成影片

### 1. 輸入故事並挑選參考素材

- 在首頁填寫 **專案名稱**、**故事草稿**，再按 **建立專案**。
- 在 **故事與全片設定** 調整最低時長（4–600 秒）、偏好的分鏡長度（4–25 秒，預設 15 秒）、長寬比、像素、擴寫程度及影片風格。**Strict**、**Balanced**、**Creative** 代表不同的故事擴寫程度。可分別勾選 **創作對白** 與 **創作旁白**，並指定語言。完成後按 **儲存設定**。
- 在 **參考影音圖檔** 拖曳檔案，或點選上傳區。可點預覽檢查原始素材。為每筆素材勾選用途，視需要填入人物名稱、參考說明，以及用逗號分隔的片段 ID。適用片段留白表示全片可用。如果手動把檔案放到 `projects/<project-id>/ref_img/`，可按 **重新掃描** 載入。
- 按 **選取內建角色** 開啟角色選擇器。可依姓名、介紹或範例台詞搜尋，按分類或有無語音篩選，也可看大頭照並試聽語音。每次最多選 30 位，再按 **加入所選角色**。每位角色會成為一筆合併素材，三視圖與語音用於對應的工作流程插槽，大頭照用於預覽。再次匯入同一角色會沿用既有素材。

若要在本機新增角色，請建立 `character_template/<分類>_<姓名>/` 並放入 `turnaround.png`（三視圖）及 `voice.wav`（語音），即可匯入。也可放入 `headshot.png`、`profile.txt` 和 `line.txt`，分別用於大頭照、角色介紹及範例台詞。選擇器會略過名稱以 `_` 或 `.` 開頭的資料夾。

### 2. 規劃與審閱分鏡

- 按 **產生／重建t2v影片藍圖**，讓 LLM 按故事、素材用途及備註規劃。全片時長會以設定的最低秒數為下限。
- 按 **產生空白分鏡** 可直接建立有時長的片段，這一步不需要呼叫 LLM。此按鈕只在專案尚未有分鏡時開放。要調整片段結構，可用各張卡片的 **在後方新增空白片段** 或 **刪除片段**。
- 展開 **編輯本段分鏡與對白**，調整時長、摘要、鏡頭 JSON 或對白／旁白 JSON。JSON 欄位請維持陣列格式，再按 **儲存本段變更**。改分鏡後，提示詞可能被標記為過期。程式會在本機估算說話所需時間。畫面中的人物說話時，請保留說話者 ID 和原台詞，並安排能看清楚說話者的近景。

### 3. 套用每段的工作流程與素材

1. 在片段卡選擇 **Workflow template** 和 **H3 任務**，再按 **套用**。第一次測試可用純文字生影片範本搭配 `T2VA`。需要圖片作為條件時，選用相容的 `I2VA` 或 `FL2VA` 範本。也可以搭配適用的工作流程使用 `L2VA` 或 `Ref2VA`。
2. 依範本需求選擇 **起始幀**，`FL2VA` 也可選 **結束幀**。含有 `[[FIRST_FRAME]]` 的 `I2VA` 或 `FL2VA` 範本可勾選 **承接前段末幀**。將本段起始幀留空，並確認上一段已有可用的 active take，才能生成承接的片段。
3. 在 **REF參考媒體插槽** 按需要的順序選素材。標籤會顯示對應的圖片、音訊和影片關鍵字。角色可以同時填圖片和音訊插槽，`Drive_AUD` 會沿用第一個選到的音訊或角色。請填滿工作流程需要的插槽，多餘的列可留空。
4. **依檔案順序填入** 會依檔案順序填入相容素材，**LLM 建議順序** 可預覽模型建議。核對標籤後按 **儲存媒體順序**。

### 4. 撰寫或編輯 H3 提示詞

- 按單段的 **生成新 prompt**，或按 **創作/重製所有prompts** 批次撰寫。程式最多會自動修正兩輪，請查看結果與格式檢查訊息。自動產生的 H3 結構和描述用英文，中文對白、歌詞和畫面文字會在生成提示詞中轉成簡體中文，原文則保存在專案內。
- 每段都應完整描述人物外觀、服裝、地點、光線、道具和開頭動作，讓各段可獨立生成。T2VA 和 Ref2VA 會載入隨附的敘事補充規則。
- 要自行撰寫，可編輯文字框後按 **儲存手動 prompt**。**修改/優化 prompt** 會把目前的草稿和素材選擇交給 LLM 修改。**插入提示詞模板** 可瀏覽 `prompt_templates/` 的常用片段。選擇 **插入** 後可接著編輯，再儲存提示詞。

### 5. 生成、挑選與合併影片

1. 按 **生成/重製本段影片** 生成單段，或按 **依序生成所有影片** 排入整個專案。影片工作逐筆執行，每次使用新的 seed。可在 **影片生成佇列** 查進度，尚在排隊的項目可按 **×** 取消。
2. 在片段卡試播結果，找到要用的輸出後按 **設為 active**。之前的 take 會留在片段卡供比較。
3. 每段都選好 active take 後，按 **合併 active takes**。FFmpeg 會依分鏡順序直接剪接，完成的影片會顯示在分鏡下方。

## 用內建工具生成分鏡圖片

**生成起始幀**、**生成結束幀**、**生成場景圖** 使用隨附的 Qwen Image 工作流程。請先在 ComfyUI 裝好相應模型與節點，也要設定撰寫用的 LLM，介面會用它替生成的圖片取簡短檔名。

1. 先填片段摘要，並在 **鏡頭 JSON** 填入至少一個鏡頭，以啟用生圖按鈕。
2. 開啟要用的生圖工具。參考素材留空可用文字生圖，也可以選最多三個圖片、角色或影片素材來編輯圖片。影片素材在此工具中會擷取一張畫面。
3. 按 **生成提示詞** 或自行填入圖片提示詞。將 **Batch（張）** 設為 1–4，再按 **生成圖**。
4. 比較結果並按 **採用此圖**。圖片會成為專案參考素材，並更新這段的對應影格或場景參考。生成影片前可核對工作流程中的素材插槽。

## 備份或搬移專案

- 等生成結束後按 **打包下載專案**，即可儲存目前的編輯內容並匯出 `.vap.zip`。專案包包含參考素材、角色資料、範本快照、各次生成結果與合併影片。
- 在另一套安裝環境的首頁按 **匯入專案包**。每次匯入都會建立新專案 ID，專案包上限為 20 GiB、20,000 個檔案。匯入時會檢查封裝版本、檔案路徑及引用的檔案。未完成的工作可在匯入後重新送出。請在目的端另行設定模型與 ComfyUI。
- **重新命名** 可修改專案名稱。**封存** 或首頁專案卡的 **刪除** 會把專案移出首頁，檔案會保留。專案儲存在 `projects/<project-id>/`，設定與分鏡位於 `project.json`。

## 常見問題

| 現象 | 檢查方式 |
| --- | --- |
| ComfyUI 連不上 | 啟動 ComfyUI，從執行 Vid Auto Prompt 的電腦確認網址與連接埠。先儲存 URL，再按 **測試連線**。 |
| 找不到工作流程 | 確認 UTF-8 的 API JSON 已放進 `workflow_templates/`，含 `[[OUTPUT_PREFIX]]`，而且各關鍵字占完整 JSON 值。重新整理專案頁面。 |
| 生成按鈕不能按 | 查看按鈕下方的狀態訊息。套用範本、確認提示詞狀態，並補齊缺少的影格或參考插槽。 |
| ComfyUI 回報缺少節點或模型 | 查看 take 上的錯誤訊息和 ComfyUI 主控台。安裝相符的節點或模型，或修正工作流程中的模型名稱後重新套用。 |
| ComfyUI 顯示 VRAM 不足 | 若與本機 llama.cpp 共用顯示卡，請確認已啟用共用 GPU。可降低解析度、縮短片段，或改用較輕量的工作流程。 |
| 無法合併 | 確認每段都有可播放的 active take，並檢查 FFmpeg 是否安裝完成。 |

## Agent CLI、MCP 與效能測試

執行 `start_agent.bat` 或 `.venv\Scripts\python.exe run.py --mode agent`，可由外部代理負責編寫分鏡、提示詞與素材選擇。此模式把 LLM 工作交給代理，影音處理仍由 ComfyUI 與 FFmpeg 執行。執行 `vap.bat --help` 可查看 JSON CLI。若要使用選用的 stdio MCP 介面，請安裝 `requirements-mcp.txt` 再執行 `vap_mcp.py`。[Agent 介面指南](docs/agent-interface.md) · [隨附的 Agent 技能](skills/vid-auto-prompt/SKILL.md)

執行 `.venv\Scripts\python.exe -m scripts.benchmark_llm --runs 2 --max-tokens 256` 可測量連線延遲、首個 token 等待時間、總耗時和 token 速率。加上 `--model provider/model-id` 可測試另一個模型，並保留原本儲存的模型選擇。
